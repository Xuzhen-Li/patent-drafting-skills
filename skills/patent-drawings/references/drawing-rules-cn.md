# 附图规则清单（中国发明专利）

对照《专利审查指南》关于附图的形式要求逐项勾选。有附图时，说明书中的附图标记与图中标记一致。

## 线条和版面

- [ ] 黑白线条图。线条均匀、清晰、着墨足够深，缩小后仍能辨认。
- [ ] 不着色。照片只在发明内容无法用线条表达时使用（例如金相组织），并在 `figure_list.md` 写明原因。
- [ ] 剖视、局部放大使用常规制图画法，剖面线不掩盖标记。
- [ ] 同一张图纸上的多幅图按图号顺序排列，互不重叠。
- [ ] 图号写在对应图的下方，形式为“图1”“图2”，使用阿拉伯数字，连续编号。不使用 “FIG. 1” 作为中国申请的图号。

## 文字

- [ ] 图内除必要词语外没有其他注释。必要词语限于流程图的简短操作、框图中的模块名称、或“开启”“关闭”这类无法用线条代替的词。
- [ ] 零件名称写在说明书里，不作为图内的长句说明。
- [ ] 图中没有商标、广告语、人名或无关边框装饰。

## 附图标记

- [ ] 标记使用阿拉伯数字。
- [ ] 同一组成部分在全部附图和说明书中只用一个标记。
- [ ] 一个标记只对应一个名称。
- [ ] 说明书写成 `壳体10` 或 `壳体(10)`，与 `07-drawings/numerals.json` 中的名称一致。
- [ ] 标记写在引出线端部，引出线不交叉穿过无关零件。
- [ ] 权利要求若引用标记，标记放在括号中，且与图中相同。

## 与说明书的对应

- [ ] “附图说明”对每一幅图有一句话，顺序与图号一致。
- [ ] 独立权利要求中的结构特征能在至少一幅图中找到。
- [ ] 方法权利要求的步骤顺序与流程图一致。
- [ ] 摘要附图只指定一幅，文件名写入 `patent.yaml` 的 `abstract_figure`。

## PCT

PCT 附图用英文图号 `FIG. 1`，纸张为 A4，物理要求见 PCT Rule 11。不要把本清单的“图1”直接用于 PCT 文本。
