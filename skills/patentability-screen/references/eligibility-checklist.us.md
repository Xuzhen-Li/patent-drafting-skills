## B. Judicial exception (MPEP 2106)

Do not stop at "it uses a computer" or "it uses a natural correlation".

| Step | Question | Result | Why, from the disclosure |
|------|----------|--------|--------------------------|
| 2A prong 1 | Does a claim concept recite an abstract idea, a law of nature, or a natural phenomenon? | | |
| 2A prong 2 | If yes, is it integrated into a practical application (a specific technical improvement the disclosure describes)? | | |
| 2B | If still exceptional, is there an inventive concept beyond the exception itself? | | Unknown is acceptable before a search |

A natural product limited only by "isolated" or "pure" is a risk, not an automatic pass. Say what structural or functional change the disclosure actually describes.

## C. Utility (MPEP 2107)

Specific, substantial, and credible. A throwaway "for treating diseases" with no disease and no data is not substantial utility.

| Question | Result | Evidence the inventor supplied |
|----------|--------|--------------------------------|
| Is a specific use stated? | | |
| Is that use substantial (a real-world use, not a research object only)? | | |
| Is it credible on the facts given, without adding mechanisms the inventor did not state? | | |
