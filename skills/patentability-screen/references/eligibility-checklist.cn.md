## A. 是不是技术方案（专利法第二条）

发明是对产品、方法或其改进所提出的新的技术方案。审查指南看技术问题、技术手段、技术效果是否同时存在。

| 问题 | 结论 | 依据（交底书哪一节） |
|------|------|----------------------|
| 保护对象是产品、方法，还是对它们的改进？ | | |
| 要解决的是技术问题，还是商业、审美、纯规则问题？ | | |
| 手段是技术手段（结构、步骤、条件），还是只是算法或商业规则本身？ | | |
| 交底书写明的效果是技术效果，还是尚未验证的预期？ | | |

涉及计算机程序的：不要用“含有软件”直接否定或肯定。按审查指南第二部分第九章，看它是否解决技术问题、采用技术手段、获得技术效果。纯智力活动规则属于专利法第二十五条。

## D. 实用性（专利法第二十二条）

能够制造或者使用，并且能够产生积极效果。交底书没有积极效果的数据时，不得写成已经具备实用性。

| 问题 | 结论 | 依据 |
|------|------|------|
| 本领域技术人员能否按交底书重复实施？缺哪些条件？ | | |
| 交底书记载的积极效果是什么？若只是预期，标为有风险 | | |
| 是否依赖独一无二、无法重复的个人技巧或偶然结果？ | | |

## F. 发明还是实用新型

实用新型只保护产品的形状、构造或其结合（专利法第二条），保护期十年（第四十二条），授权前不进行实质审查。方法、没有形状构造的组合物、纯算法，不建议实用新型。
