# 说明书模板（中国发明专利）

写入 `05-description/description.md`。正文使用中文。五部分按下列顺序排列，这是《专利法实施细则》和《专利审查指南》（2023）对说明书内容的常规结构。说明书应当清楚、完整，以所属技术领域的技术人员能够实现为准；摘要应当简要说明技术要点（专利法第26条第3款）。权利要求书应当以说明书为依据（专利法第26条第4款）。

不要在 Markdown 里预写 `[0001]`。导出时由 `patent-docx-export` 给说明书段落编号。未提供的数据写 `【待发明人确认】`。

## 技术领域

写明要求保护的技术方案所属的技术领域，与独立权利要求的主题一致。

```
本发明涉及【领域】，尤其涉及一种【主题名称】。
```

## 背景技术

写对理解、检索和审查有用的背景技术。引证 `02-prior-art/` 中已有的文献，写明公开号和检索记录里的链接。只写该文献明确公开的内容。

```
【文献公开号】公开了一种【对象】，其包括【文献中的特征】。该方案在【发明人指出的具体缺陷】方面仍有不足。【若发明人未说明缺陷：【待发明人确认】】
```

不使用商业性贬低用语。不把领域通识写成某一篇文献的内容。

## 发明内容

分三块，并与权利要求对应。

1. 要解决的技术问题。问题应能由背景技术中的缺陷导出。
2. 技术方案。用说明书语句复述每项独立权利要求的全部必要技术特征，并写上重要的从属特征。此处用“包括”“所述”，不要把“其特征在于”当作说明书套话堆叠。
3. 有益效果。只写发明人提供了依据的效果，并指向具体特征。没有实验或对比数据时写 `【待发明人确认】`，不写“显著提高”“最佳”。

```
为解决上述问题，本发明采用如下技术方案。
一种【主题】，包括【特征】。所述【特征】【连接或步骤关系】。
在一种实施方式中，所述【从属特征】。
本发明的有益效果是：【有依据的效果，或【待发明人确认】】。
```

## 附图说明

有图时逐幅说明。图号用“图1”“图2”。此处分配的附图标记在后文保持不变。

```
图1是【主题】的结构示意图。
图2是【方法】的流程示意图。
```

同时写出 `07-drawings/numerals.json`：

```json
{
  "figures": [
    {"id": "图1", "numerals": {"10": "壳体", "12": "传感器"}}
  ]
}
```

正文中的写法须能被标记检查读到：`壳体10` 或 `壳体(10)`。同一零件只用一个标记，同一标记只对应一个名称。

## 具体实施方式

结合附图，给出至少一种完整的实施方式，使技术人员能够实现独立权利要求。再写入交底书中已经出现的变体、材料替换和可选步骤。

```
下面结合附图对本发明作进一步说明。
如图1所示，传感装置包括壳体10和设置在壳体10内的传感器12。传感器12【发明人写明的安装或信号关系】。
在另一实施方式中，【交底书中的替代方案】。未记载的尺寸、温度和次数为【待发明人确认】。
```

每项权利要求的每个技术特征都应能在本节或“发明内容”中找到同一名词和同一关系。对应关系记入 `05-description/support_matrix.md`。

无附图时仍须写明至少一种实施方式，并在“附图说明”中写“无附图”或省略该部分中的图号，不要虚构图。
