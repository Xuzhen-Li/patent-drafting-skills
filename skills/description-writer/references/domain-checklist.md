# Domain checklist

Copy this file to `05-description/domain_review.md`. Mark each domain
`applies` or `not this invention`. A combination can mark more than one.
Where a row applies, either point at a disclosure paragraph or write
`【待发明人确认】` / `[INVENTOR TO CONFIRM]`. Generic filler is not a
substitute for the missing fact.

Do not invent a machine part, a pin, a software module, a process
condition, a spectrum, a structure, or a sequence to close a row.

## Machine / 机械

- [ ] Each claimed part is in the parts master, with the connection or motion the claim recites.
- [ ] Materials and dimensions appear only when the inventor supplied them.
- [ ] An assembly sequence a skilled person would need is written, or marked missing.

## Circuit / 电路

- [ ] Inputs, outputs, and the function of each block are stated.
- [ ] Component values appear only from the inventor. No guessed resistor, voltage, or clock.
- [ ] A block diagram is planned only for blocks the disclosure names.

## Software / 计算机程序

- [ ] The technical setting is stated: the data, the hardware or process it controls, and the technical effect.
- [ ] A business result, a price, or a user-interface wish is not written as the technical effect.
- [ ] CN: 审查指南 Part II Chapter 9 asks for a technical problem, technical means, and technical effect. A pure algorithm or business rule stays a fact for `patentability-screen`, not a rewritten claim.

## Process / 方法

- [ ] Steps are in the order the inventor uses.
- [ ] Temperatures, times, concentrations, and equipment are sourced or marked missing.
- [ ] The starting material and the result of the process are identified.

## Chemistry / 化学

- [ ] Structures, formulas, and conditions come from the inventor.
- [ ] No spectrum, chromatogram, gel, or yield curve is described unless the inventor's data file is named.
- [ ] No chemical structure is drawn from an image model. See `patent-drawings`.

## Biology / 生物

- [ ] The organism, material, or sequence the inventor actually used is named, and nothing else is added.
- [ ] Complete `references/biology-reminder.md` when this row applies. Do not draft sequences or fill a deposit number.
- [ ] A diagnostic or treatment method is not renamed into a device to avoid the subject-matter screen. Send that question back to `patentability-screen`.

## Combinations

If two domains apply, say which claim features belong to which domain.
Do not leave a crossed-out domain looking like it was enabled.
