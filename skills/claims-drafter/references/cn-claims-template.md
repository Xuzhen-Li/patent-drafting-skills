# 权利要求书模板（中国发明专利）

正式文本写入 `04-claims/claims.md`。一项权利要求为一句话。编号用 `1.` 或 `1．`。未知内容写 `【待发明人确认】`，不要编造参数或效果。

法律要点（撰写时自查，不代替代理师意见）：

- 权利要求书应当以说明书为依据，清楚、简要地限定要求保护的范围（专利法第26条第4款）。保护范围以权利要求的内容为准，说明书及附图可以用于解释权利要求（专利法第64条）。
- 独立权利要求（独立权利要求）从整体上反映技术方案，写明解决技术问题的必要技术特征（必要技术特征）。
- 两段式：前序部分写主题名称以及与最接近的现有技术共有的必要技术特征；特征部分用“其特征在于”写明区别技术特征。两部分合在一起限定保护范围。两段式明显不适合该发明时，可以改用一段式，并在 `claim_map.md` 里说明原因。
- 从属权利要求包括引用部分和限定部分，只能引用在前的权利要求，并用附加技术特征作进一步限定。
- 引用两项以上权利要求的多项从属权利要求，只能以择一方式引用，用语用“或”或“任一项”。多项从属权利要求不得作为另一项多项从属权利要求的基础（实施细则第25条）。
- 附图标记可以写在括号中，便于阅读；标记本身不额外扩大或缩小保护范围。标记必须与说明书、附图一致。

## 产品独立权利要求

```
1. 一种【主题名称，例如：传感装置】，包括【与最接近的现有技术共有的必要技术特征，例如：壳体】，其特征在于，还包括【区别技术特征A】和【区别技术特征B】，所述【区别技术特征A】【与前述特征的结构或连接关系】。
```

前序里已经出现的名词，特征部分用“所述”。特征部分第一次出现的零件用“一种”“一个”“若干”或“至少一个”，或先裸写名词再使用“所述”。

## 方法独立权利要求

```
2. 一种【主题名称，例如：温度检测方法】，包括【共有的必要步骤】，其特征在于，还包括：
【步骤S1，写明操作对象和条件】；
【步骤S2】。
```

方法权利要求仍是一句话，步骤之间用分号。不要把未提供的温度、时间、压力写成具体数值。

## 系统独立权利要求

```
3. 一种【主题名称，例如：检测系统】，包括【模块或装置的封闭清单】，其特征在于，所述【模块名称】用于【发明人已写明的功能】，并与所述【另一模块】连接。
```

功能表述必须能在说明书里找到对应的结构或步骤。避免只写“处理模块，用于处理数据”这类没有结构的句子。

## 用途权利要求

仅当交底书写明了用途时使用。

```
4. 【产品主题】在【具体用途】中的应用。
```

## 从属权利要求

单一从属，进一步限定一个特征：

```
5. 根据权利要求1所述的【主题名称】，其特征在于，所述【已引入的名词】为【进一步的结构、材料或连接关系】。
```

择一的多项从属。父项本身不能也是多项从属：

```
6. 根据权利要求1或2所述的【主题名称】，其特征在于，所述【名词】【附加特征】。
```

```
7. 根据权利要求1至3中任一项所述的【主题名称】，其特征在于，所述【名词】【附加特征】。
```

错误示例（脚本应报错，正式文本中不要出现）：

- `根据权利要求1和2所述`（“和”不是择一引用）。
- `根据权利要求1、2所述`（顿号连接多项，没有“或”或“任一项”）。
- 权利要求8引用权利要求6或7，而6和7本身已经是多项从属。
- 权利要求2引用权利要求3（在后引用）。
- 尚未出现“壳体”就写“所述壳体”。

## 引用关系速查

| 关系 | 是否可用 |
| --- | --- |
| 从属权利要求引用一项在前的独立或从属权利要求 | 可用 |
| 多项从属，用“或”或“任一项”引用在前的权利要求 | 可用 |
| 多项从属再作为另一项多项从属的基础 | 不可 |
| 引用自身或在后的权利要求 | 不可 |
| 用“和”同时引用两项 | 不可 |
